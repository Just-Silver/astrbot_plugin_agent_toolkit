# web_fetch 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 AstrBot Agent 注册一个不依赖搜索服务商 Key 的 `web_fetch` 工具，能抓取网页、提取正文并以 Markdown 返回。

**Architecture:** 四层分离——URL 校验与 SSRF（`fetch.py`）、HTTP 抓取与解码（`fetch.py`）、正文提取与格式化（`extract.py`）、业务编排与工具包装（`service.py` / `tool.py`）。`main.py` 只负责读配置和注册工具。

**Tech Stack:** Python 3.10+、httpx（异步 HTTP）、trafilatura 2.x（正文提取）、pytest、ruff。

**Spec:** `docs/superpowers/specs/2026-10-26-web-fetch-design.md`

## Global Constraints

- 响应上限 5 MB；重定向最多 5 跳；URL 长度上限 2048
- 超时默认 30 秒，可配 5–120；`max_chars` 默认 8000，可配 1000–50000
- `format` 只有 `markdown` 与 `text`
- 依赖只有 `trafilatura>=2.0.0` 和 `httpx>=0.27.0`；不得引入 `markdownify`、`requests`、`beautifulsoup4`
- 正文提取必须用 `favor_precision=True`（默认参数会带入 `<nav>` 文本）
- 不做降级、不做缓存、不做自动链接抓取、不提供域名白名单
- SSRF 拦截无开关；写死 CIDR 清单 + `is_global` 兜底 + IPv4-mapped 拆解
- 工具失败一律返回 `Error: ...` 字符串，不向 Agent Runner 抛异常
- 代码注释用英文，docstring 用 Google 格式（`Args:` / `Returns:` / `Raises:`）
- `ruff` 最新版，`line-length = 120`，`target-version = "py310"`，`select = ["F","W","E","ASYNC","C4","Q","I","UP"]`

## Review Focus

1. **302 跳转到内网**：短链、图片 CDN 常把目标藏在重定向后面。期望被拒绝，而不是跟随之后再报错。
2. **GBK/GB18030 老站点**：中文站点大量使用旧编码。期望中文正常显示，不是乱码。
3. **`blocked_hosts` 带端口**：用户可能填 `example.com:8080`。期望按 host 匹配，端口不影响判断。
4. **超大页面**：`content-length` 缺失或撒谎时，期望在流式读取中及时中断并报错，不是读完 100MB 再失败。
5. **`max_chars` 调大后**：期望截断提示里的数字与总长度仍然准确，不会出现 `start=0` 死循环。

import asyncio

import httpx
import pytest

from webfetch import fetch
from webfetch.errors import FetchError
from webfetch.fetch import fetch_page


@pytest.fixture
def allow_public(monkeypatch):

def run_fetch(handler, *, url="https://example.com/", timeout=30, fmt="markdown"):

    return asyncio.run(_run())


def test_returns_decoded_html(allow_public):

def test_maps_http_error(allow_public):
    with pytest.raises(FetchError, match="HTTP 404"):
        run_fetch(lambda r: httpx.Response(404, headers={"content-type": "text/html"}, text="missing"))


def test_follows_redirect(allow_public):
    def handler(request):
        if request.url.path == "/start":
            return httpx.Response(302, headers={"location": "/final"})
        return httpx.Response(200, headers={"content-type": "text/plain"}, text="done")
    page = run_fetch(handler, url="https://example.com/start")
    assert page.url == "https://example.com/final"
    assert page.text == "done"

    assert run_fetch(lambda r: httpx.Response(200, content=b"raw body")).text == "raw body"

- 异常映射：`httpx.TimeoutException → timed out after {timeout}s.`；`httpx.HTTPError → request failed: {exc}`

from astrbot.api import AstrBotConfig, logger, star
from .webfetch.tool import WebFetchTool

DEFAULT_MAX_CHARS = 8000
DEFAULT_TIMEOUT = 30


def _positive_int(value: object, default: int) -> int:
    try:
        parsed = int(value)  # type: ignore[arg-type]
    except (TypeError, ValueError):
        return default
    return parsed if parsed > 0 else default


class Main(star.Star):
    def __init__(self, context: star.Context, config: AstrBotConfig | None = None) -> None:
        super().__init__(context, config)
        self.config = config or {}
        if not self.config.get("enabled", True):
            logger.info("web_fetch is disabled by plugin config.")
            return
        self.context.add_llm_tools(WebFetchTool(
            max_chars=_positive_int(self.config.get("max_chars"), DEFAULT_MAX_CHARS),
            timeout=_positive_int(self.config.get("timeout"), DEFAULT_TIMEOUT),
            blocked_hosts=[str(item) for item in self.config.get("blocked_hosts", []) if str(item).strip()],
        ))

    async def terminate(self) -> None:
        """Release resources. The tool holds none."""
