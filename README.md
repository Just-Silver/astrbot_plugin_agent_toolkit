# astrbot_plugin_agent_toolkit

为 AstrBot Agent 提供一组通用工具的插件集合。

当前版本为仓库骨架，尚未注册任何工具。

## 规划中的工具

| 工具 | 说明 | 状态 |
|---|---|---|
| `web_fetch` | 抓取网页并提取正文，返回 Markdown / 纯文本 / HTML；含大小、超时上限与 SSRF 防护 | 待实现 |
| 消息动作扩展 | 引用回复、表情、撤回等 IM 原生动作 | 规划中 |
| 记忆写入 | 让 Agent 主动记住 / 遗忘 / 检索长期信息 | 规划中 |
| TTS 发声 | 复用已配置的 TTS 提供商，输出语音文件供发送 | 规划中 |

## 安装

AstrBot 支持从仓库链接安装插件：

```
https://github.com/Just-Silver/astrbot_plugin_agent_toolkit
```
